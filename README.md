# Notes_UdS

Ce dépôt a été créé pour permettre aux étudiants du baccalauréat en mathématiques à l'Université de Sherbrooke d'avoir une version PDF des notes de certains cours qui n'en offrent pas. De plus, je suis en train de concevoir des outils spécialisés pour assister les étudiants dans certains cours.

## Notes de cours

Les liens ci-dessous dirigent vers des fichiers PDF qui contiennent les notes de cours que j'ai écrites. Les fichiers sont ouverts dans le même onglet, en utilisant le lecteur de PDF natif du navigateur. Pour ouvrir le fichier dans un nouvel onglet, accédez à l'option avec un clic droit, utilisez CTRL+clic ou cliquez avec la roulette de votre souris.
